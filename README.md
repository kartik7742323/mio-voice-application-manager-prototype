# Mio AI Voice in Application Manager · Prototype

A clickable prototype for launching Mio AI Voice in Meritto's Application Manager: Mio Voice config forms in Dynamic Activity, Application Manager agent setup, sending applications to an agent, the job report and the Outcome Dashboard.

Open `index.html` in a browser, or use the GitHub Pages link for this repo. Everything runs in the page with invented sample data; nothing is sent anywhere.
